Git

Git es un sistema de control de versiones distribuidas. Su función principal es rastrear todos los cambios realizados en el código de un proyecto a lo largo del tiempo, permitiendo guardar el historial, volver a versiones anteriores y trabajar en equipo de manera ordenada.

¿Para qué sirve?

  • Máquina del tiempo: Permite "volver al pasado" y restaurar el código si una nueva función rompe el programa o si comete un error, evitando tener carpetas duplicadas con nombres como proyecto_final_v2.zip.
  • Trabajo en equipo: Facilita que varias personas trabajen en el mismo proyecto simultáneamente sin sobrescribir el trabajo de los demás.
  • Ramas (Branches): Permite crear copias paralelas del código para probar nuevas ideas o funciones de forma segura sin modificar la versión principal.

GitHub

GitHub es una plataforma en la nube que funciona como un "Google Drive" para programadores. Aloja proyectos de software y utiliza el sistema de control de versiones Git, permitiendo a los desarrolladores guardar su código, colaborar de forma remota y llevar un registro de cada cambio realizado.

¿Para qué sirve?

  • Control de versiones: Permite guardar el historial de un proyecto y volver a cualquier versión anterior si algo sale mal (como una máquina del tiempo).
  • Trabajo en equipo: Facilita que múltiples personas modifiquen el mismo código al mismo tiempo sin sobrescribir el trabajo de los demás.
